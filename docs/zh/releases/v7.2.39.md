# v7.2.39 — Person governance：阻止继续产生幽灵人物

- Series 只维护自身 main cast；Episode cast / guest stars 保持单集归属，不再提升到父 Series。
- 人物写入以冻结 provider 身份与 Emby 实例 ID 为目标，写入前重新核验。姓名不能授予写入资格，同名异人不被批量修改。
- actor limit 只作为最大上限，不补满 50；在昂贵补充前完成范围过滤、身份去重和限额。
- 不完整同步不解绑旧映射；冲突导入、维护和 upsert 不覆盖或自动合并不同身份。
- 移除临时姓名创建、失败解绑及危险回滚链，改为持久待复核与精确已有对象复用。

## 支持边界与安全收紧

自动创建采用 **existing-only**：EVH 仅复用精确已有 Person。缺失、歧义、身份变化或操作结果不确定时停止并保留证据，不自动创建、解绑、删除或重放。

这会暂停部分新演员的自动补充，尤其是 Douban-only 人物。无法精确保留的旧关联及超过处理上限的历史关联会 HOLD，不通过截断历史 People 制造新 orphan。

本版本不删除、合并或清理历史人物，不改变 Person Cleanup 删除资格或 DeletePerson 合同；不新增数据库 schema，不声称能原子控制第三方对 Emby 的并发写入。

VidHub、Infuse、Recent、官方 Emby 虚拟库和首页排序保持现有行为。没有操作 NAS 生产环境。

正式镜像：`tzyzero186/emby-vision-hub:7.2.39`。
